# VibeMatch Frontend — React + TypeScript (Vibe & Activity Match)

Фронтенд дипломного проекта **«Разработка веб-приложения для знакомств с декларативным описанием правил подбора пар»**.

## Ключевые модули
- **Декларативный хук `useDeclarativeMatchFeed`**: реактивно управляет параметрами композиции правил (`.And()`, `.Or()`) и синхронизирует состояние с бэкенд-движком `Specification<UserAccount>`.
- **Механика «Вайб дня» (`DailyVibeBanner`)**: установка спонтанного плана с таймером и мгновенная фильтрация ленты по категории активности.
- **Живой инспектор AST-выражений**: прямо над лентой карточек отображается скомпилированная формула спецификации и сгенерированное C# дерево выражений `Expression<Func<UserAccount, bool>>`.
- **Real-Time чат с контекстом активности (`MatchesChatPage` + `useSignalRMatchHub`)**: при взаимном лайке открывается чат с баннером общего «Вайба дня» через SignalR.

## Запуск
```bash
npm install
npm run dev
```
